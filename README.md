# Netflix Content Intelligence Dashboard

## 📌 Project Overview

This project is an interactive Netflix Content Intelligence Dashboard built using **Streamlit**, **Pandas**, and **Plotly**. The dashboard allows users to explore Netflix Movies and TV Shows through dynamic filters, KPI cards, and interactive visualizations.

The goal of this project is to transform raw Netflix data into meaningful insights using data visualization and dashboarding techniques.

---

## 🎯 Objective

* Build an interactive dashboard using Streamlit
* Analyze Netflix content distribution and trends
* Enable dynamic filtering and exploration
* Visualize key business insights from the dataset

---

## 📂 Dataset

Dataset Used:

* `netflix_titles.csv`

The dataset contains information about:

* Title
* Type (Movie / TV Show)
* Director
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre

## 📊 Dashboard Features

### KPI Cards

* Total Titles
* Total Movies
* Total TV Shows
* Total Countries

### Interactive Filters

* Content Type
* Country

### Visualizations

#### 1. Movies vs TV Shows

* Interactive Pie Chart

#### 2. Ratings Distribution

* Bar Chart of Content Ratings

#### 3. Netflix Growth Over Years

* Line Chart showing content additions over time

#### 4. Top Countries

* Top 10 countries contributing content

#### 5. Top Genres

* Most popular genres available on Netflix

#### 6. Top Directors

* Directors with the highest number of titles

#### 7. Dataset Explorer

* Interactive data table for filtered results

---

## 📈 Key Insights

* Movies dominate Netflix's content library.
* The United States contributes the highest number of titles.
* Netflix experienced rapid growth in content additions after 2015.
* TV-MA and TV-14 are among the most common ratings.
* International Movies and Dramas are highly represented genres.
* Several directors have contributed multiple titles to the platform.
